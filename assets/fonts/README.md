# Fonts

## gdk-test-font.ttf — generated for the tests

Generated by `make_test_font.py`. Run the script to regenerate or extend it; the tests do not need Python, only the `.ttf`.

Legibility is not the goal - every glyph is a rectangle. The purpose is:
- **It is available on all development systems.** So tests dont fail because a font isnt installed.
- **Its metrics are known.** So tests can assert exact advances, exact kerning and
  exact vertical metrics, rather than "greater than zero" against whatever font is available on the host system.

It covers ASCII, ten hiragana, twenty kanji and one codepoint above the BMP, so four
byte UTF-8 is exercised end to end.

## gdk-test-font.ttc — generated for the tests

The same script writes a two-face collection of the same glyphs. Face 0 is `gdk-test-font.ttf`,
table for table. Face 1 has an 1100 ascender and a -300 descender, so its ascent to descent is 1400
units of the 1000 unit em. That one difference tests both `font_settings::face`, since the ascent
shows which face was read, and `font_sizing::em`, since the two sizings agree on face 0 and differ
on face 1. The faces share no tables; the format allows sharing but does not require it.

## LiberationSans-Regular.ttf — vendored for the demo

`LiberationSans-Regular.ttf`, licensed under the SIL Open Font License 1.1 — see `LICENSE.txt`.

The demo needs a real font rather than rectangles.
Its stored here in the repo rather than loaded from the host so that the text demo looks the same
on different machines + this way it works under emscripten.

The OFL requires that this licence travel with the font, and that any modified version be renamed.
This copy is unmodified.
